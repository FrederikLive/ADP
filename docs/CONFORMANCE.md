# ADP Conformance

This document is explanatory; `ADP.md` remains normative.

**ADP-aware:** an agent can reliably locate/read the applicable protocol.

**ADP-bootstrapped:** ADP established an appropriate project control plane, command surface, verification expectations, safe file/Git handling, and continuity behavior.

**Continuity-ready:** a cold successor can determine the active objective, status, contract, worktree state, verification state, next recommended phase, and exact next action without the previous conversation.

**Transition-transparent:** a human can determine what meaningful outcome just completed, what was verified, the current milestone, what phase is recommended next, why it is next, and whether execution will CONTINUE, CHECKPOINT, or COMPLETE.

**Delegation-safe:** when delegation or concurrent mutation is used, user intent survives delegation, concurrent writers are isolated, mutable ownership is controlled, delegated completion is reconciled before becoming authoritative state, and unresolved unlanded work is preserved.

**Assignment-safe (conditional):** when role/model routing is used, authority remains tied to the human and existing Authorization Envelope; hard provider/privacy/spending eligibility precedes optimization; missing capability or quota is reported honestly; failover preserves and verifies repository state; no unapproved paid fallback or fabricated model switch occurs. Automatic model switching is never required for conformance.

**Reading-efficient:** agents distinguish REQUIRED, CONDITIONAL, and REFERENCE material, determine applicability before skipping specialized sections, and never weaken normative requirements because explanatory material is deferred.

**Analysis-reconciled:** external reports are treated as untrusted evidence; every finding is independently assessed, dispositioned with rationale, tracked or linked, and verified where implemented. The original source and reconciliation remain traceable; unresolved/deferred findings stay visible.

Delegation is optional. A conformant ADP project/harness may execute entirely with one agent when that is the smallest sufficient execution topology.

Conformance is behavioral, not cosmetic.
