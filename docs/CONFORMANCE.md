# ADP Conformance

This document is explanatory; `ADP.md` remains normative.

**ADP-aware:** an agent can reliably locate/read the applicable protocol.

**ADP-bootstrapped:** ADP established an appropriate project control plane, command surface, verification expectations, safe file/Git handling, and continuity behavior.

**Continuity-ready:** a cold successor can determine the active objective, status, contract, worktree state, verification state, next recommended phase, and exact next action without the previous conversation.

**Transition-transparent:** a human can determine what meaningful outcome just completed, what was verified, the current milestone, what phase is recommended next, why it is next, and whether execution will CONTINUE, CHECKPOINT, or COMPLETE.

Conformance is behavioral, not cosmetic.
