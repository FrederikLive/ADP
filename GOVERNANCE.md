# Governance

**Project:** ADP — Agent Development Protocol  
**Maintainer:** Frederik Smith (`@FrederikLive`)  
**Email:** w5zk8yjto@mozmail.com

ADP uses a maintainer-led open contribution model. Anyone may propose changes or submit pull requests. The maintainer has final responsibility for normative changes, releases, governance, licensing, and conflicting proposals.

Prefer agent reliability, human agency and safety, portability, continuity, verification, low context overhead, maintainability, and simplicity. Avoid vendor lock-in.

Breaking normative changes require MAJOR; compatible normative additions MINOR; clarifications PATCH.
