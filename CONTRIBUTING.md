# Contributing to ADP

Read `ADP.md`, `AGENTS.md`, `GOVERNANCE.md`, and `docs/VERSIONING.md` first.

Normative changes alter expected agent behavior and must explain the problem, proposed rule, compatibility, safety, autonomy, continuity, and alternatives. Non-normative changes clarify documentation without changing required behavior.

Pull requests should have one coherent purpose, synchronize derived artifacts, update the changelog/version when required, and pass `python scripts/validate.py`.

AI-assisted contributions are welcome; contributors remain responsible for correctness, provenance, license compatibility, and validation.
